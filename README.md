**Apoloxias** — это безопасная модульная платформа с графическим интерфейсом, предназначенная для защищённой коммуникации, обмена данными и расширения функционала через систему изолированных плагинов (модулей).

## 🔑 Ключевые особенности

- 🔒 **Безопасность по умолчанию**: Встроенные механизмы шифрования (`core/crypto.py`) и конфигурируемые настройки скрытия сетевого трафика (`core/network_stealth.py`).
- 🧩 **Модульная архитектура**: Ядро приложения отделено от бизнес-логики. Новый функционал добавляется через папку `modules/` без необходимости перекомпиляции или изменения ядра.
- 🛡️ **Песочница и контроль прав**: Модули не имеют прямого доступа к ядру или GUI. Взаимодействие осуществляется строго через `AppProxy`, который требует явного подтверждения прав (`request_permission`) для чувствительных операций.
- 🖥️ **Графический интерфейс**: Удобная система аутентификации (`gui/login_window.py`) и главное окно управления (`gui/main_window.py`).
- 🔄 **Встроенный Update Manager**: Механизм для безопасного обновления как ядра, так и отдельных модулей.

## 📂 Структура проекта

├── apoloxias.py          # Точка входа и инициализация платформы
├── core/                 # Ядро системы
│   ├── auth.py           # Управление аутентификацией и сессиями
│   ├── config.py         # Работа с конфигурационными файлами
│   ├── crypto.py         # Криптографические операции
│   ├── module_api.py     # API для взаимодействия модулей с ядром
│   ├── module_manager.py # Загрузчик и диспетчер модулей
│   └── network_stealth.py# Механизмы защиты и маскировки сетевого трафика
├── gui/                  # Графический интерфейс пользователя
│   ├── login_window.py   # Окно входа в систему
│   └── main_window.py    # Главное окно приложения
├── modules/              # Каталог модулей (плагинов)
│   ├── ChatModule/       # Модуль защищённого текстового чата
│   ├── VoiceChat/        # Модуль голосовой связи
│   ├── FileShare/        # Модуль обмена файлами
│   ├── UpdateManager/    # Модуль обновлений
│   └── ExampleModule/    # Шаблон для создания собственных модулей
└── logs/                 # Директория для журналов событий (создается автоматически)

🚀 Начало работы
Требования
Python 3.8 или выше
Зависимости (уточните актуальный список в будущем requirements.txt, пока используются стандартные библиотеки и выбранный GUI-фреймворк)
Установка и запуск

Клонируйте репозиторий:
  git clone https://github.com/liremi686-stack/Apoloxias.git
  cd Apoloxias
  
(Рекомендуется) Создайте и активируйте виртуальное окружение:
  python -m venv venv
  source venv/bin/activate  # Для Linux/macOS
# или
  venv\Scripts\activate     # Для Windows

Запустите приложение:
bash
  python apoloxias.py
  
🧩 Разработка собственного модуля
Платформа поддерживает горячую загрузку модулей. Чтобы создать свой модуль:
Скопируйте папку modules/ExampleModule и переименуйте её.
Отредактируйте manifest.json, указав имя, версию и описание модуля.
Реализуйте логику в main.py, используя предоставленный AppProxy для взаимодействия с ядром (например, для отправки уведомлений или запроса прав доступа).
Пример запроса права из модуля:

python
if self.app.request_permission(self.name, "ACCESS_NETWORK"):
    # Выполнить сетевую операцию
    pass
